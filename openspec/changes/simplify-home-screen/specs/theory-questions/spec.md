# Spec Delta

## MODIFIED Requirements

### Requirement: Mixed mode
Mixed mode SHALL randomly combine Notes, Scales and Chords questions within one session. It SHALL NOT include Guitar or Bass questions.

#### Scenario: Mixed session content
- **WHEN** a Mixed session is played
- **THEN** every question is a Notes, Scales or Chords question

## REMOVED Requirements

### Requirement: Key Notes mode
**Reason**: Spotting a note that does not belong to a key is not a skill the user wants to train, and the mode is not enjoyable.
**Migration**: None. The mode is removed from the home screen; Notes and Scales modes cover which notes belong to each key.
